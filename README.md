# Reajuste_Pre-o_Simulacao_Margem
Análise de reajuste de preço e simulação de margem por categoria (Google Sheets + Power BI). Identifica subcategorias com desconto acima da média corroendo a rentabilidade, calcula a correlação estatística entre desconto e margem, e simula cenários de reajuste com dashboard interativo (parâmetro What-if em DAX).
